# Android Architecture & Design

A topic-wise interview guide covering modern Android application architecture, state management, dependency injection, modularization, navigation, lifecycle, offline-first design, testing, and system design.

## Recommended interview lens

For every architecture decision, ask:

- What problem does this solve?
- Who owns the state?
- What are the dependencies and their direction?
- What happens on failure, recreation, and process death?
- How will this be tested?
- What happens as features and engineers scale?
- Is the abstraction actually paying for its complexity?
